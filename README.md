# Mossline Launcher

**Mossline** is a third-party Minecraft launcher designed for personal use by the community. 

## Purpose
This application is used to allow players to log in with their official Microsoft accounts, manage their game profiles, and verify ownership of Minecraft to comply with the Mojang/Microsoft EULA. It does not bypass authentication or provide unauthorized access to the game.

## Features
* Secure Microsoft OAuth 2.0 login.
* Modpack management and support for Fabric mods.
* Clean and optimized user interface.
